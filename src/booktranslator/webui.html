Chọn sách cần dịch

Kéo thả file EPUB / TXT / Markdown vào đây. File được lưu trong thư mục làm việc.

Kéo thả file sách vào đây, hoặc bấm để chọn file

Sách đã dịch (*.vi.*) và file kết quả không hiện ở đây — xem ở bước 5.

Bộ khởi đầu Discworld

Chép file hướng dẫn dịch Discworld và bảng tên riêng đề xuất vào thư mục làm việc, rồi tự chọn sẵn ở bước 2.

Cài đặt dịch

Các lựa chọn được nhớ lại cho lần sau.

Phong cách tự học (bước ★) hiện ở đây dưới dạng file .json.

Claude Code dùng gói Claude Pro/Max bạn đang đăng nhập — không tốn tiền API. Các mục còn lại cần API key (bước ⚙).

Sửa nội dung ở bước 3.

Dùng chung một sổ tay cho cả bộ truyện để tên thống nhất.

Hướng dẫn dịch

Đây là "prompt" riêng cho cuốn/bộ sách: giọng văn, giọng nhân vật, cách xử lý câu đùa. Sửa tự do bằng tiếng Việt.

Sổ tay tên riêng

Mỗi tên chỉ có một bản dịch, dùng cho cả cuốn/bộ. Bấm "Lập sổ tay" ở bước 5 để AI đọc sách và điền tự động, rồi sửa lại ở đây.

Tất cả file kết quả

    Học phong cách từ sách tham chiếu

    Ví dụ: đưa vào bản Harry Potter do Lý Lan dịch (và bản tiếng Anh nếu có). AI đọc vài trích đoạn, rút ra giọng văn, cách đặt tên, xưng hô và đoạn mẫu. File kết quả chứa trích đoạn sách của bạn — chỉ dùng cá nhân.

    Tiến độ hiện ở bước 5. Xong thì chọn file này trong "Phong cách dịch giả".

    Kết nối AI

    Trạng thái các nhà cung cấp. API key nhập ở đây chỉ giữ trong bộ nhớ đến khi tắt giao diện — muốn lưu lâu dài, đặt biến môi trường (xem README).

    Claude Code: cài tại claude.com/claude-code, mở Terminal gõ claude rồi đăng nhập một lần. Khi dùng Claude Code, phần mềm cố ý không truyền API key để không bị tính tiền API.
