Phong cách tự học (bước ★) hiện ở đây dưới dạng file .json.

Codex dùng gói ChatGPT để dịch; khi hết hạn mức hoặc gặp lỗi, phần dịch chuyển sang DeepSeek. Claude Code dùng gói Claude để hiệu đính bản dịch; nếu Claude Code hết hạn mức thì Codex hiệu đính, chỉ khi cả hai đều hết mới dùng DeepSeek. Hai mục dùng gói đăng nhập không tính tiền API; DeepSeek cần API key (bước ⚙).

Chọn Pro cho chất lượng ưu tiên hoặc Flash để tiết kiệm chi phí. Lựa chọn này áp dụng mỗi khi DeepSeek được dùng để dịch hoặc hiệu đính.

    Kết nối AI

    Trạng thái các nhà cung cấp. API key nhập ở đây chỉ giữ trong bộ nhớ đến khi tắt giao diện — muốn lưu lâu dài, đặt biến môi trường (xem README).

    Claude Code (dùng gói Pro/Max — không tốn tiền API)

    1. Cài Claude Code: mở PowerShell và chạy irm https://claude.ai/install.ps1 | iex (macOS: curl -fsSL https://claude.ai/install.sh | bash).
    2. Mở cửa sổ PowerShell mới, gõ claude, đăng nhập bằng tài khoản Claude của bạn, rồi gõ /exit.
    3. Bấm Kiểm tra kết nối bên dưới.

    Tìm đường dẫn: trong PowerShell gõ where.exe claude (macOS: which claude).

    Codex (dùng gói ChatGPT Plus/Pro — không tốn tiền API)

    1. Cài Node.js (bản LTS) nếu máy chưa có.
    2. Mở PowerShell/Terminal mới, chạy npm install -g @openai/codex
    3. Chạy codex login và đăng nhập bằng tài khoản ChatGPT của bạn.
    4. Bấm Kiểm tra kết nối bên dưới.

    Mới cài Codex khi giao diện đang mở? Hãy đóng cửa sổ đen của Mo-giao-dien.bat rồi mở lại. Tìm đường dẫn: mở PowerShell mới, gõ where.exe codex (macOS: which codex). Không ra gì nghĩa là chưa cài Codex CLI (ứng dụng Codex hay tiện ích VS Code là thứ khác) — chạy npm install -g @openai/codex.

    Claude Code: cài tại claude.com/claude-code, mở Terminal gõ claude rồi đăng nhập một lần. Khi dùng Claude Code, phần mềm cố ý không truyền API key để không bị tính tiền API.
